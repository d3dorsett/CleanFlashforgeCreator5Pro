This is an ugly script, however,  it did what I needed it to do.

On the Flashforge Creator 5 Pro I was experimenting with different firmware, reforge and Z-mod. 
When I went to restore back to factory defaults, I did not have enough room.

I developed this script based on my own personal printer and it has not been tested elsewhere.
Use at your own risk.

To Use:
Format a USB stick to FAT32, just like if you were doing a firmware upgrade.
Copy this script and name it runFirmwareExe.sh

Notepad users: Make sure to save the file as UTF-* LF, otherwise it will not work

Plug it in and restart the printer. It will collect several list of files for your review, before and after
it deletes many common folders. There are not safe guards use at your own risk.

Enjoy!
